# Sistema-de-Acompanhamento-de-Pontos
Sistema desenvolvido em Python para registrar serviços realizados, calcular pontuação e comissão e armazenar o histórico utilizando SQLite.  O projeto começou como um exercício de lógica de programação e evoluiu para uma aplicação com persistência de dados em banco de dados.

Tecnologias:
Python
SQLite
SQL

Versão 1
→ Dicionários e estruturas de controle
→ Cálculo de pontos

Versão 2
→ Organização do sistema
→ Histórico de serviços

Versão 3
→ SQLite
→ Persistência dos dados
→ Registro de usuários
→ Histórico após fechar o programa
